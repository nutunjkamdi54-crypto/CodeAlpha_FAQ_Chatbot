# 🤖 Dev AI Assistant

An AI-powered FAQ Chatbot built using Flask, Python, NLP and Machine Learning.

## 🚀 Features

- Modern Dark Blue + Teal UI
- FAQ-based AI Chatbot
- Natural Language Processing (NLP)
- Voice Input (Speech Recognition)
- Voice Output (Text-to-Speech)
- Chat History Sidebar
- Responsive Design
- Fast Flask Backend

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- Scikit-Learn
- NLP (TF-IDF + Cosine Similarity)

## ⚙️ Installation

1. Clone repository

git clone https://github.com/nutunjkamdi54-crypto/CodeAlpha_FAQ_Chatbot.git

2. Install dependencies

pip install -r requirements.txt

3. Run application

python app.py

4. Open browser

http://127.0.0.1:5000
